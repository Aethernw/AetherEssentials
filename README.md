# AetherEssentials

![AetherEssentials](aetheressentials2.png)

Official essentials plugin for Aethernw, built for Paper 1.20+ servers.

## Installation

1. Place `AetherEssentials-1.0.0.jar` into the `plugins` folder.
2. Start the server once, then edit `config.yml` and fill in your MySQL credentials under the `database:` section.
3. Restart the server. Database tables are created automatically.

## Build

```bash
mvn package
```

Output: `target/AetherEssentials-1.0.0.jar`
